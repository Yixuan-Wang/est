## Installation

You can find the latest Docker image in the Action run.
Port 3000 is exposed by default.
Set `EST_PUBLIC_URL` to the absolute URL Est is served at (e.g. `https://est.example.com`); the server refuses to start without it, since browsers need it to add Est as a search engine.
Not stable, use at your own risk.
