## Installation

You can find the latest Docker image in the Action run.
Port 3000 is exposed by default.
Set `EST_PUBLIC_URL` to the absolute URL Est is served at (e.g. `https://est.example.com`); browsers need it to add Est as a search engine. It defaults to `http://localhost:3000`, which only works on the machine running Est.
Not stable, use at your own risk.
